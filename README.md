# WearOSPDFReader

WearOSPDFReader is a standalone PDF document viewer and bookmark manager for Wear OS smartwatches.

## Features
- Render PDF files directly on the watch screen from internal storage\n- Invert mode (Pitch Black OLED view) for high battery savings\n- Save and jump to page bookmarks\n- Scrollable control settings menu fitting watch screen bezels

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.
